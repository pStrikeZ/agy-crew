# agy-crew 0.9.9 — `inspect`, a live tabbed viewer

Runs, account selection, cooldowns and quota behave as in 0.9.8. This release adds one command for people: `agy-crew inspect`.

## What's new

**`inspect [<job>]`** is a resident, tmux-style full-screen window for watching jobs while they run.

- Tab 0 is the **Jobs** page: recent jobs, running first, or `No tasks currently running.` when idle. Select one and press Enter to open it, including finished jobs.
- Every running job gets its own tab, including jobs started after the window opened. A tab tails the job's event stream: one line per tool call (`▶` start, `✓`/`✗` finish with duration and an output excerpt) plus the model's reply, and a status line with state, model, account, elapsed time, tool/error counts, tokens and the last tool.
- The window never exits on its own; finished jobs stay as tabs and an idle window waits for the next job. `q` or Ctrl-C quits, and quitting never cancels or signals a job.
- Keys: `Tab`/`←→` switch, `0`–`9` jump, `↑↓` `PgUp` `PgDn` `g` `End` scroll, `Enter` open, `x` close a tab, `m` toggle the mouse.
- Mouse: the wheel scrolls (or moves the selection on the Jobs page); clicking a tab switches, clicking a job row opens it. While mouse reporting is on, hold Shift to select text as usual, or start with `--no-mouse`.
- It is read-only: it does not write `state.json` and does not affect `wait`.

**`inspect <job> --plain`** is the scriptable form (also used when stdout is not a terminal, or with `--no-follow`): a scrolling log of one job that follows it to the end and exits with the job's code (0/3/4/5). `--no-color` disables colour.

A job that finished warning-free has no raw event stream left (unchanged behaviour); its tab says so and points to `result`. Agents should keep using `wait` and `observe`; `inspect` is for people.

## Upgrading

```bash
npm install -g agy-crew@latest
agy-crew install
```

Restart the harness. No migration is needed.
