# agy-crew 0.9.2 — steadier tests, import docs

A maintenance release. The companion, the skills and the account pool behave exactly as in 0.9.1.

## Changes since 0.9.1

**Steadier tests.** The test that observes a job while its success cleanup runs polled a fixed 30 times and gave up when a loaded machine needed longer for the job to finish. It now polls densely until a 60-second deadline, so it still covers the race and no longer depends on machine speed. Three other waits that gave up after one second (process exit and event-file cleanup in the recovery and streaming tests) now wait on deadlines too.

**Import docs.** `accounts import <name> --home <dir>` is documented with the concrete agy-cli-manager location, `~/.agy-cli-manager/accounts/<name>`. agy-crew does not depend on agy-cli-manager; import is a file copy plus the same email and duplicate checks as `accounts login`.

## Upgrading

```bash
npm install -g agy-crew@latest
agy-crew install
```

Restart the harness. No migration is needed.
