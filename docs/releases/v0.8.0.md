# agy-crew 0.8.0 — fork and cross-harness installer

agy-crew is a fork of [agy-staff](https://github.com/keli-wen/agy-staff) by Keli Wen (MIT). Version numbering continues the agy-staff history, whose last release was 0.7.4; the older notes under `docs/releases/` are kept as inherited history.

## Changes since agy-staff 0.7.4

**Fork and rename.** All product names derive from one identity module, `companion/identity.mjs`. Every identifier changed with it:

- Harness plugin id `agy-crew@agy-crew` (marketplace `agy-crew`, plugin `agy-crew`).
- Invocations: Claude Code plugin route `/agy-crew:staffer`, Codex plugin route `$agy-crew:staffer`, Pi `/skill:agy-crew-staffer`, OpenCode `/agy-crew-staffer`, and `/agy-crew-staffer` for user-level skills on every harness.
- Per-repository state directory `.agy-crew/` (was `.agy-staff/`); global per-user directory `~/.agy-crew/`, overridable with `AGY_CREW_HOME`.
- Telemetry line tag `[agy-crew]`; error prefix `agy-crew error:`.

**`agy-crew` terminal command and `install`.** The package now ships an `agy-crew` bin. `agy-crew install` renders the skills once into `~/.agy-crew/bundles/<version>-<digest>/` and links that bundle into every detected harness (Claude Code, Codex, Oh My Pi, OpenCode, DeepSeek Harness), replacing per-harness plugin caches. Flags: `--hosts`, `--all`, `--dry-run`, `--status`, `--json`. `agy-crew uninstall [--hosts …|--all]` removes only the links it created. Anything in a skills directory that the installer did not create is never overwritten, and any conflict aborts the whole run before writing. Pi is not covered by `install`; the plugin-manager routes for Claude Code, Codex, Pi and OpenCode remain available. See the [install command reference](../REFERENCE.md#install-command).

**Mutual exclusion with agy-staff.** agy-crew and agy-staff must not be installed together: the skills would appear twice and both companions would write the same per-repository state. `agy-crew install` refuses to run beside agy-staff and prints how to remove it.

**Unchanged.** Personas, background jobs, the companion command surface and `setup` (which still edits the global `~/.gemini/antigravity-cli/settings.json`) behave as in agy-staff 0.7.4.

**Planned, not in this release.** An account pool for running concurrent jobs on different agy accounts, with per-account, per-model-family quota awareness, is planned for the next releases. It is not available in 0.8.0.

## Installing and upgrading

```bash
npm install -g github:pStrikeZ/agy-crew
agy-crew install
```

Restart the harness, then run `/agy-crew-ask reply with OK`.

There is no in-place upgrade from agy-staff. Uninstall agy-staff first (`claude plugin uninstall agy@agy-staff` for Claude Code; remove the plugin for Codex, OpenCode or Pi; remove any upstream flat skills), then install agy-crew. Per-repository state in `.agy-staff/` is not migrated; it is left untouched and can be deleted once no agy-staff jobs are needed. See the [upgrade instructions](../REFERENCE.md#upgrading).
