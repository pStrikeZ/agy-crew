# agy-crew 0.9.8 — Gemini quota is back in `accounts quota`

Runs, account selection and cooldowns behave as in 0.9.7. This release fixes `accounts quota --refresh`, which had stopped reporting the Gemini pool.

## Changes since 0.9.7

**Gemini quota snapshots.** Cloud Code now returns the Gemini group from `retrieveUserQuotaSummary` only when the request's User-Agent names a recent agy CLI (`antigravity/cli/<version> (...)`, as agy itself sends). agy-crew sent a bare `antigravity`, so every refresh came back with the Claude/GPT pool only: `accounts list` and `accounts quota` showed no `gemini` rows, and `auto` could neither rank accounts by Gemini quota left nor skip an account whose Gemini quota was empty. agy's own usage view was unaffected.

Quota requests now send `antigravity/cli/<version> (aidev_client; os_type=<os>; arch=<arch>)`, with the version read from `agy --version` once per refresh (1.4.9 when it cannot be read). Run `agy-crew accounts quota --refresh` once after upgrading to bring the Gemini snapshots back.

## Upgrading

```bash
npm install -g agy-crew@latest
agy-crew install
agy-crew accounts quota --refresh
```

Restart the harness. No migration is needed.
