# agy-crew 0.9.1 — packaging and docs

A maintenance release. The companion, the skills and the account pool are unchanged from 0.9.0; this version brings the npm package page up to date and moves releases onto CI.

## Changes since 0.9.0

**Install from npm.** agy-crew is on the npm registry: `npm install -g agy-crew`, then `agy-crew install`. The README, the reference and the agent install guide now use it; `npm install -g github:pStrikeZ/agy-crew` remains for trying unreleased changes on `master`.

**Install routes in the README.** The install section starts from a comparison of the three routes (npm, `git clone` + `node` without npm, harness plugin managers), followed by a First run walkthrough (smoke test, optional pool accounts, everyday use) and update and uninstall commands for every route.

**Branding.** The logo, the design diagram and the background-job diagram now read agy-crew and show the `/agy-crew-*` invocations. The two upstream screenshots, which still showed agy-staff's `/agy:` commands, are no longer in the README. The Community section was removed.

**Packaging.** `bin` no longer has the `./` prefix that npm rewrites on publish, so publishing prints no warning.

**Releases.** Tagging `vX.Y.Z` runs the Release workflow: it checks that the tag matches every version field and that release notes exist, runs the skill check and the test suite, publishes to npm through trusted publishing with provenance, and creates the GitHub Release. The workflows use `actions/checkout@v5` and `actions/setup-node@v5`. The release process is documented under Contributing.

## Upgrading

```bash
npm install -g agy-crew@latest
agy-crew install
```

Restart the harness. No migration is needed.
