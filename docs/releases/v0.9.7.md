# agy-crew 0.9.7 — login with an id_token_email token

Runs, account selection and quota handling behave as in 0.9.6. This release fixes account login with token files written by newer agy versions.

## Changes since 0.9.6

**Login no longer fails on an `id_token_email` token.** agy records the signed-in account in its token file either as an `id_token` JWT or, in newer versions, as a plain `id_token_email` field. agy-crew only read the JWT, so a sign-in that produced the second form failed with `could not read an email from the token; refusing to add an account that cannot be told apart`, and a re-login of such an account was rolled back. The email is now read from either field. Accounts already in the pool need nothing.

## Upgrading

```bash
npm install -g agy-crew@latest
agy-crew install
```

Restart the harness. No migration is needed.
