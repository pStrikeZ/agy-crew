# agy-crew 0.9.15 — transient omp extension and per-account concurrency

Background runs, `start`, and the permission model behave as in 0.9.14. This release changes the omp bridge, the installer, and account-pool scheduling.

## Changes

- **`agy-crew install` no longer installs the omp plugin.** The extension loader is no longer part of an install; the command now removes a loader that an earlier version wrote. A file the user put at `~/.omp/agent/extensions/agy-crew-omp.ts` is left alone.
- **The omp extension lives only as long as an `agy-crew omp` run.** The launcher writes the bundled extension before omp starts and removes it when omp exits, including after a refused or failed run. The old installed-extension check and `AGY_CREW_OMP_SKIP_INSTALL_CHECK` are gone.
- **`agy-crew omp` requires `--use-at-my-own-risk`.** Loading an installed extension into omp is not a supported omp interface and can break the session. Without the flag the command refuses before holding an account, writing a file, or launching omp. `--help` still works without it.
- **`accounts parallel <name> [<n>]` limits agent-dispatched runs per account.** Skill-driven runs (`staffer`, `research`, `review`, `implement`, `ask`, `continue`, `restart`) take one slot per account by default; the command raises that to 1–64 for one account without requiring it to be idle. `auto` picks an account with a free slot, and a run fails with reason `busy` when none is available. Interactive `start` and `agy-crew omp` still hold their account exclusively. A credential on loan is exclusive whatever the limit: neither lender nor borrower takes another run until the loan is restored, and a loan never starts while the borrower has another run lease. `accounts list` gains a `PARALLEL` column and `--json` includes `parallel`, so the caller can size a batch to the free slots.

## Upgrading

```bash
npm install -g agy-crew@latest
agy-crew install
```

`install` retires the loader written by 0.9.14. Restart the harness, and restart any running `agy-crew omp` session. Existing `agy-crew omp` commands need the new flag:

```bash
agy-crew omp --use-at-my-own-risk work1 -- --model google-antigravity/gemini-3.8-flash
```

Existing pool accounts keep working with one slot each; raise a limit only when you want several jobs on one account.
